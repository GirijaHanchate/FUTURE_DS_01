# FUTURE_DS_01

 Sales Performance Analysis Dashboard

🔍 Project Summary

Developed an interactive Sales Performance Dashboard using Power BI to analyze business sales data and extract meaningful insights. The dashboard helps track revenue performance, product demand, regional sales trends, and order distribution, supporting data-driven decision-making.

🎯 Project Goals

Perform data cleaning and transformation
Analyze overall sales performance
Identify top-selling products and categories
Evaluate regional sales distribution
Track sales trends over time
Create interactive business intelligence dashboard

🛠 Tech Stack

Power BI – Data visualization & dashboard creation
Excel / CSV – Data source
Power Query – Data cleaning & transformation
DAX (Data Analysis Expressions) – KPI calculations

📂 Dataset Details

The dataset includes key business sales attributes:

Order ID
Product Name
Category
Region
Sales Amount
Quantity Sold
Order Date

📈 Dashboard Components
⭐ Key Performance Indicators (KPIs)

Total Sales Revenue
Total Orders Count
Total Quantity Sold

📊 Sales Insights

Sales by Product Category
Sales by Region
Sales Trend Over Time

🛍 Product Performance Analysis

Top Selling Products
Product-wise Revenue Distribution

🔎 Key Business Insights

Technology category contributes the highest revenue.
West region generates the maximum sales.
Laptop and Phone are the top-performing products.
Sales trend indicates seasonal variations and growth opportunities.

Successfully created a professional and interactive sales dashboard that allows businesses to monitor performance, identify growth opportunities, and make strategic decisions.
